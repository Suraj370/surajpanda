# Suraj Panda — Portfolio

A gold & black personal portfolio built with **Next.js**, **Tailwind CSS**, and **shadcn/ui**.

## Features

- **Hero** with rotating roles: Full Stack Engineer ↔ UI/UX Designer
- **Projects** section with tech tags and demo/code links
- **Achievements** section
- **Contact** footer — opens the user’s mail client (`mailto:`)
- Email shown as `surajpanda2077@gmail[.]com`
- Gold text on a black theme

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command         | Description              |
| --------------- | ------------------------ |
| `npm run dev`   | Start development server |
| `npm run build` | Production build         |
| `npm run start` | Run production server    |
| `npm run lint`  | Run ESLint               |

## Customize

- Projects: edit `src/components/projects.tsx`
- Achievements: edit `src/components/achievements.tsx`
- Contact email: edit `src/components/contact.tsx`
- Theme colors: edit CSS variables in `src/app/globals.css`
